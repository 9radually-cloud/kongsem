1. 왜 만들었나

4. 사용 방법 (따라 하기)

단계할 일입력 예시화면 결과
1도구를 열고 학생 계정으로 로그인합니다.등록된 학년·반·번호·이름·비밀번호학생 학습 화면이 열립니다.
2위 메뉴에서 “그래프”를 누릅니다.별도 입력 없음학년에 맞는 그래프 종류가 표시됩니다.
3그래프 종류를 고르고 제목을 입력합니다.4학년 막대그래프 / 좋아하는 과일 조사선택한 그래프와 제목이 표시됩니다.
4표에서 항목 이름과 수를 입력합니다. 필요하면 “항목 더 넣기”를 누릅니다.사과 8, 바나나 5, 포도 7입력한 자료가 그래프에 반영됩니다.
5그래프와 요약을 살펴보고 값을 바꿔 비교합니다.사과의 수를 8에서 10으로 변경그래프와 자료 요약이 즉시 갱신됩니다.

도형을 살펴보려면 “도형” 메뉴를 누릅니다. 3학년은 직각삼각형·정삼각형·정사각형 버튼으로 도형을 만들고, 4학년은 “새 도형 그리기”를 누른 뒤 꼭짓점을 차례로 찍어 삼각형이나 사각형을 만듭니다.

6. 주의 사항과 한계

  • 개인정보 보호: 이름, 연락처, 학교 계정 비밀번호 등 개인정보를 그래프나 콩이 대화에 입력하지 않습니다.
  • 입력 제한: 그래프 제목은 최대 48자, 항목 이름은 최대 8자입니다. 항목은 2~6개, 수는 0~1000 사이의 정수로 입력합니다.
  • 학년별 제공 기능: 그래프 종류는 학년에 따라 다릅니다. 3학년 그림그래프, 4학년 막대·꺾은선그래프, 5학년 그래프 복습·평균, 6학년 띠·원그래프를 제공합니다.
  • 결과 저장: 그래프 파일 저장 기능은 없으므로 필요한 결과는 화면 캡처로 보관합니다.
  • AI 답변 확인: 콩이의 설명이나 계산이 항상 정확하다고 가정하지 말고 교과서와 선생님을 통해 확인합니다.
  • 기록 공유: 학생의 대화와 학습 기록은 담당 교사에게 공유될 수 있으므로 개인적인 내용을 입력하지 않습니다.

7. 자주 막히는 문제와 해결 방법

문제해결 방법
로그인할 수 없어요.학년·반·번호·이름이 등록 정보와 일치하는지 확인합니다. 처음 설정하거나 비밀번호를 잊었다면 선생님에게 인증 코드를 요청합니다.
원하는 그래프가 보이지 않아요.현재 학년에서 제공하는 그래프인지 확인합니다. 그래프 종류는 학년에 따라 달라집니다.
입력한 값이 그래프에 나타나지 않아요.항목 이름과 수를 확인합니다. 항목은 최소 2개가 필요하며 수에는 0 이상의 정수를 입력합니다.
항목을 더 넣을 수 없어요.항목은 최대 6개입니다. 쓰지 않는 항목 옆 “×”를 눌러 삭제한 뒤 새 항목을 추가합니다.
콩이가 같은 안내를 반복해요.현재 단원이나 학년 수준의 수학 개념을 구체적으로 물어봅니다. 예: “분모가 같은 분수를 더할 때 분모는 왜 그대로인가요?”
화면이 제대로 열리지 않아요.인터넷 연결을 확인하고 페이지를 새로고침합니다. 계속되면 선생님이나 도구 운영자에게 문의합니다.
